# Banner Images

Place your concert banner images from LinkedIn here. Name them as follows:

- `home.jpg` or `home.png` - Homepage banner
- `about.jpg` or `about.png` - About page banner  
- `project.jpg` or `project.png` - Projects page banner
- `friend.jpg` or `friend.png` - Links/Friends page banner
- `media-server.jpg` or `media-server.png` - Media Server Commission page banner

You can use either JPG or PNG format. The images will be automatically optimized by Astro.
